Implemented features

All three team features are integrated.

  • Add tasks with unique IDs and validated, trimmed titles.
  • Complete tasks and reopen them as pending.
  • List all tasks, pending tasks, or completed tasks.

Running the project

Use Python 3.12 or later:

git clone https://github.com/soulaymanealahiane/GitLab-Assignment2.git
cd GitLab-Assignment2
python -m pip install -r requirements.txt
python -m todo
python -m pytest

Tasks are stored in memory for the current session.

Choose 1 to add a task, 2 to complete a task, 3 to reopen a task, 4 to list all tasks, 5 to list pending tasks, 6 to list completed tasks, or 0 to exit. Completion and reopening ask for the task ID shown in the lists.
