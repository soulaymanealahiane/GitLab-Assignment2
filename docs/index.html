Running the project

After the feature Pull Requests are merged, use Python 3.12 or later:

git clone https://github.com/soulaymanealahiane/GitLab-Assignment2.git
cd GitLab-Assignment2
python -m pip install -r requirements.txt
python -m todo
python -m pytest

Tasks are stored in memory for the current session.
