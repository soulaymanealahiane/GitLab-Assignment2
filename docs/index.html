To-Do List

Assignment 2 group project. Theme: To-Do List.

Team and assigned features

  • Soulaymane Alahiane: add tasks with validated titles and unique IDs.
  • Aya Drissi: complete and reopen tasks.
  • Rim Zemmouri: filter tasks and integrate the command-line menu.

Implemented features

  • Add tasks with unique IDs. Titles are trimmed, blank titles are rejected, and new tasks start as pending.
  • Complete tasks and reopen completed tasks using their IDs.
  • Filter tasks to display all tasks, pending tasks, or completed tasks. The original task order is preserved.
  • Use a command-line menu to manage tasks, with messages for invalid choices, invalid input, and missing task IDs.

Running the project

Use Python 3.12 or later. Run these commands from the project folder:

git clone https://github.com/soulaymanealahiane/GitLab-Assignment2.git
cd GitLab-Assignment2
python -m pip install -r requirements.txt
python -m todo
python -m pytest

The first commands download the project and install its dependencies. Run python -m todo to open the menu, or python -m pytest to run the tests.

Command-line menu

  • 1: Add a task.
  • 2: Complete a task by entering its ID.
  • 3: Reopen a task by entering its ID.
  • 4: List all tasks.
  • 5: List pending tasks.
  • 6: List completed tasks.
  • 0: Exit the program.

Tasks are stored in memory for the current session. They are not saved when the program exits.
