Implemented features

Add tasks with unique IDs. Titles are trimmed, and blank titles are rejected. New tasks start as pending.

Running the project

Use Python 3.12 or later:

git clone https://github.com/soulaymanealahiane/GitLab-Assignment2.git
cd GitLab-Assignment2
python -m pip install -r requirements.txt
python -m todo
python -m pytest

Tasks are stored in memory for the current session.

Choose 1 to add a task or 0 to exit. Completion and filtering are assigned to the other team members.
